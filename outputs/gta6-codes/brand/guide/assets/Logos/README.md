# Logos

- `gtad-logo-horizontal-dark.svg` / `-light.svg`: the primary logo (keys, wordmark and tagline).
- `gtad-logo-stacked-dark.svg` / `-light.svg`: keys above the wordmark.
- `gtad-wordmark-dark.svg` / `-light.svg`: words only.
- `gtad-avatar.svg` and `gtad-avatar-1080.png`: the profile picture (keys on a purple glow). Upload the PNG to Instagram, TikTok and YouTube.

The letters are outlines, so no font is needed. Don't redraw or recolour them.
