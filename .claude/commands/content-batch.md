# /content-batch [N] — Bulk content producer

> Turn N rows of the weekend plan into finished, ready-to-schedule posts in one run. Built for volume (the weekend 30). Default N = 10.

## Instructions

Read `outputs/content/weekend-sprint/30-post-plan.md`. Take the next **N** rows with Status = Draft (in order) and produce each fully.

### For every post
Produce and save the finished piece:
- **3 hook options** (the first 2 seconds are the whole reel — nail these).
- **The body:** reel script (20–30s) OR carousel slides (one thought per slide) OR the screen-record "what to show, in order."
- **Caption + hashtags + one CTA** (DM a keyword or "free audit / quick chat" → the Calendly link `https://calendly.com/hello-wilba/30min`).
- In Jess's voice (Brand Bible: plain English, real numbers, no em-dashes, no "unlock/dive in"). Health-adjacent → AU-compliant (no prescription-med brand names, no before/afters, no testimonials).

### By format — produce the assets
- **Faceless reel (FR):** launch **visual-producer** → generate the **Artlist voiceover** from the script + **3–5 b-roll clips** + a cover. (See `outputs/social/artlist-automation.md`.)
- **Carousel (C):** generate the **cover** (Higgsfield/Artlist) + write the exact **slide text** for Jess to drop into the Canva template.
- **Talking-head (TH):** output the shot reference (already in `batch-film-shotlist.md`) + a cover. No generation — Jess films these.
- **Screen-record (SR):** output the exact "record this, in this order" capture list + a cover. No generation.

### Save + track
- Save each finished post to `outputs/content/weekend-sprint/posts/[NN]-[slug].md`.
- Update the row's Status → **Produced** in `30-post-plan.md`.
- Log any generated visuals to `outputs/content/visual-log.md` with credits spent.

### Report
Tell Jess: how many produced, which need filming vs are done, total credits spent, and the single next action (film the 5, or assemble the faceless reels).

## Rules
- **Preflight credits** on the batch — be efficient (count:1 for supporting b-roll, count:2 only for hero covers).
- Reuse the source scripts in the plan (`30-post-authority-bank.md`, `scripts/builder-reels-*`, skill library) — don't rewrite from scratch; sharpen and produce.
- If Artlist/Higgsfield is disconnected, produce all the copy + hand Jess the exact prompts to run in the app (per `artlist-automation.md`) and still mark the copy done.
- Keep it moving — this is a production line, not a meeting.
