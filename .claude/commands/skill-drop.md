# /skill-drop [topic] — The Albert Engine

> The @ai_with_albert model, systemised: every post **gives away a real skill/resource**, ends with *"comment [WORD] and I'll send it,"* and looks pro. This is how you become the go-to authority — by being the most *generous* person in the niche.

## Instructions

Given a topic (`$ARGUMENTS`) — or today's angle from **trend-scout** — produce a complete "skill drop": the giveaway, the post, the keyword+DM, and the visual.

### Step 1 — Build the GIVEAWAY first (this is the whole play)
Create the actual resource people will receive — genuinely useful on its own:
- a copy-pasteable **Claude skill / prompt pack / template / mini-guide** that delivers a real win in <10 min.
Save it to `outputs/content/skill-library/[slug].md`. Rule: **give more than feels comfortable.** Generosity IS the authority. If the giveaway is thin, the whole post fails.

### Step 2 — Write the POST (authority + teach)
Launch **hook-writer**. The Albert formula: **teach one sharp idea → show real proof → give the skill away → soft CTA.** Reel or carousel. It teaches the *idea* behind the skill and points to the free resource. End with the comment CTA.

### Step 3 — The KEYWORD + auto-DM
- Pick a keyword (short, memorable — often the skill's name, e.g. `BOOKINGBOT`).
- Write the **public comment auto-reply** ("Sent! check your DMs 📩") + the **DM** that delivers the resource link and a soft line toward the next step (email capture → Skool). Slots into `outputs/content/funnel/comment-to-dm-flow.md` (Manychat).

### Step 4 — The VISUAL (make it look amazing)
Launch **visual-producer** — use Higgsfield or Artlist for b-roll + a branded cover, and a **screen-record of the skill actually working** (the proof shot). On-brand palette, clean captions.

### Step 5 — Deliver
Package it all: post copy · the giveaway resource (saved) · keyword · DM copy · visual. Add the drop to `outputs/content/skill-library/README.md` (the running arsenal). Give Jess a 3-line summary + "post-ready."

## Rules
- **The giveaway must be real and genuinely useful** — that's the entire authority engine.
- Every drop grows the **skill library** = your compounding lead-magnet arsenal.
- One keyword per post; comment-to-DM delivers it; email capture feeds the Skool.
- Keep Jess's voice + brand throughout.
